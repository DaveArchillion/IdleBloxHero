# IBH-001 — Roblox Project Foundation

## Status

READY

## Priority

P0

## Owner

NONE

## Dependencies

None

## Objective

Create the minimum clean Roblox project foundation for Idle Blox Hero.

The project must be synchronized through Rojo and organized for long-term
server/client/shared development.

## Scope

### In Scope

- Rojo project configuration
- ReplicatedStorage shared structure
- ServerScriptService structure
- StarterPlayer client structure
- minimal server bootstrap
- minimal client bootstrap
- shared bootstrap if required
- basic project verification

### Out of Scope

- combat
- heroes
- enemies
- inventory
- economy
- UI systems
- persistence
- marketplace
- monetization

## Required Structure

Create a minimal data-driven structure that clearly separates:

Shared
Server
Client

Do not introduce a framework unless there is a demonstrated need.

## Architecture Constraints

- Server authoritative
- Client is presentation/input only
- No gameplay authority on the client
- No God module
- No circular dependency
- Keep dependencies minimal
- Do not add Knit
- Do not add Fusion
- Do not add Roact
- Do not add ProfileService
- Do not add unnecessary packages

## Expected Result

A blank Roblox place can connect through Rojo and start successfully.

Server bootstrap executes without errors.

Client bootstrap executes without errors.

## Tests

- Validate project structure
- Validate Rojo configuration
- Validate module loading

## Roblox Studio Verification

Connect the project through Rojo.

Start Play/Server.

Verify:

- server starts
- client starts
- no startup errors
- bootstrap messages appear
- no unexpected warnings/errors

- [ ] Client boot verified
- [ ] Roblox Studio verified
