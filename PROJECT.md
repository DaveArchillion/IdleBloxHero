# Idle Blox Hero

Project ID: IdleBloxHero

Platform:
- Roblox
- PC
- Tablet
- Mobile

Goal:
Build an original idle anime-fantasy RPG with automatic hero combat,
stage progression, heroes, enemies, equipment, accessories, materials,
chests, inventory, enhancement, synthesis, crafting, progression,
missions, premium currency, marketplace, offline EXP + Gold,
and scalable long-term live-service architecture.

Initial priority:
Complete a playable core game before adding optional systems.

Important:
The game may use high-level gameplay inspiration from existing idle RPGs,
but must use original code, assets, names, text, and implementation.
